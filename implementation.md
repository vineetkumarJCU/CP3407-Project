# Delivered Solution

## Implemented Features

* Restaurant browsing
* Navigation flow
* Authentication
* Cart and checkout
* Transparent pricing
* Restaurant details

## Delivered UI

The Android prototype was built using Kotlin and Jetpack Compose.

Screenshots from emulator and physical testing devices are included to demonstrate the delivered solution.

## Deployment Direction

The system is designed for future cloud deployment using:

* Backend API
* MySQL on Amazon RDS
* AWS EC2
