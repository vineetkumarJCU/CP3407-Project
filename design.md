# System Design

## Overview

This section describes the architecture, database, and UI design of FeedMe.

## Architecture

* Android App (Frontend)
* Node.js Backend
* MySQL Database
* AWS Hosting

## Database Design

Entities:

* Users
* Restaurants
* Orders
* Reviews

## Interface Design

Screens:

* Login
* Home
* Restaurant List
* Order Screen

Design focuses on usability, simplicity, and efficiency.
