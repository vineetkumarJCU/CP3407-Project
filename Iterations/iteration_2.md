# Reflection
Iteration 2 focused on **business-facing features and customer retention features**.

Major completed outcomes:
- vendor menu CRUD
- analytics dashboard
- admin approval workflow
- sustainability scoring
- persistent saved restaurants
- order persistence + tracking
- customer reviews
- recommendation UI
- sales reporting

The actual velocity improved from iteration 1 because:
- project structure was already stable
- reusable top bar components reduced UI effort
- Compose navigation flow was already solved
- shared orange theme improved faster screen production

This iteration significantly increased the **commercial realism** of FeedMe and aligned strongly with the project’s differentiators:
transparent pricing, sustainability, vendor analytics, and smart customer engagement.
