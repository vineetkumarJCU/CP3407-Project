# Tools and Technologies

## Development Tools
The following tools were used to design, build, deploy, and test the FeedMe system:

- **Android Studio** — mobile application development
- **Kotlin** — Android programming language
- **Jetpack Compose** — user interface framework
- **Node.js** — backend runtime
- **Express.js** — REST API development
- **npm** — package management for backend dependencies
- **MySQL Workbench** — database connection, schema creation, and testing
- **Amazon RDS** — cloud-hosted MySQL database
- **AWS Console** — database provisioning and cloud configuration
- **GitHub** — version control and documentation
- **Draw.io / UML tools** — architecture diagram creation
- **GenMyModel** — ERD / database design

## Backend Dependencies
The backend API used the following packages:

- `express`
- `mysql2`
- `cors`
- `dotenv`

## Why These Tools Were Chosen
These tools were selected because they support:

- full-stack application development
- cloud deployment
- database scalability
- clean separation between frontend, backend, and data storage
- maintainable and realistic software engineering workflow
