User Story 4 – Place Order
Title: Order Food
Priority: High
Estimate: 5 ideal days
Description
As a customer,
I want to select menu items and place an order,
So that I can receive food delivery.
Acceptance Criteria
User can add items to cart
Total price updates dynamically
Transparent delivery fee displayed
Order is saved in database
Confirmation message displayed
Business Value
Primary revenue-generating feature.
